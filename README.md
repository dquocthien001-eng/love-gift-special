# Love Gift Special 💗

Website quà tặng tình yêu bằng HTML/CSS/JavaScript, sẵn sàng deploy Vercel.

## Deploy lên Vercel
1. Giải nén thư mục.
2. Vào https://vercel.com/new và đăng nhập.
3. Đưa thư mục này lên GitHub (tạo repository mới), sau đó chọn **Import** repository trên Vercel.
4. Framework Preset: **Other**; Build Command: để trống; Output Directory: để trống.
5. Nhấn **Deploy**.

Hoặc cài Vercel CLI và chạy `npx vercel --prod` ngay trong thư mục.

## Sử dụng
- Nhấn **Tùy chỉnh** để nhập tên, người gửi và lời chúc.
- Nhấn hộp quà để mở.
- Nhấn **Sao chép link** để chia sẻ lời chúc đã tùy chỉnh (được mã hóa trong URL, không cần cơ sở dữ liệu).

Lưu ý: liên kết mẫu không thể được truy cập trong môi trường tạo dự án, nên đây là bản thiết kế cùng chủ đề, không phải bản sao chính xác giao diện gốc.
